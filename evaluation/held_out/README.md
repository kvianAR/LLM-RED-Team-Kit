# Independent held-out evaluation

The harness accepts operator-supplied frozen suites using the documented reference schema. No independent held-out efficacy result is claimed in this release. The bundled reference suite is a public deterministic regression suite.

Before a model-backed release claim, obtain independently authored cases, group related variants, freeze the suite hash and model versions, define labels before running, and avoid tuning on the frozen set. Publish counts, uncertainty, incomplete execution, and limitations.
