# Original paired corpus

Created by [@kvianAR](https://github.com/kvianAR). Original content is licensed under CC-BY-4.0.

There are 48 executable input cases in five boundary groups and four families. Twenty-four are forbidden-outcome probes and twenty-four are authorized/benign controls. Each is tested against both vulnerable and protected fixture modes. Input variants within a group are related cases, not independent vulnerability classes.

The deterministic router consumes declared operations and arguments. Natural-language messages are representative inputs for adapting a real model target; the fixture does not establish their effectiveness against an LLM.

## Author review checklist

- One primary boundary and explicit principal/resource context.
- Correct OWASP 2025 mapping and registered prerequisites.
- Protected counterpart and legitimate control behavior.
- Observed execution/disclosure evidence rather than a model's claim.
- Group related variants and report family/group counts alongside case counts.
- Record content hash, license, and author review provenance.
- No third-party payloads or licenses imported without attribution.

Review status is author-reviewed and mechanically tested. Independent security review is pending.
