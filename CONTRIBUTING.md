# Contributing

Created by [@kvianAR](https://github.com/kvianAR).

Use Python 3.11+ and `uv sync --frozen --all-extras`. Run `uv run ruff check src tests`, `uv run ruff format --check src tests`, and `uv run pytest -q` before proposing a change.

Keep policy, observed execution, and assessment separate. A new scenario needs one primary boundary, registered preconditions, a protected counterpart, a legitimate control, evidence expectations, and provenance. Group related variants. Never add customer secrets or scan artifacts to a change.

Keep development, tuning, and genuinely frozen evaluation material separate. Changing a frozen suite or its scenario definitions requires an explicit dataset version/provenance update. A public reference suite does not become independent held-out evidence by renaming it.

Code contributions use Apache-2.0. Original corpus contributions use CC-BY-4.0. Preserve third-party licensing and attribution. Disclosures follow the owner's approved security process.
